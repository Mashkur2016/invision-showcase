# InVision: Multimodal Vision-AI Desktop Assistant

> **Showcase repository.** This repo documents the project (architecture, design decisions, results). The source code is private; walkthroughs and code review are available on request.

**Status:** v0.1.0 · Independent project (2026)

## What it is
A Windows desktop app that sends a screen capture or pasted image to a vision-language model and returns an instant answer.

## Features
- Live mode that responds when the screen changes
- Follow-up chat
- Whisper speech-to-text
- Provider-agnostic multimodal layer (Gemini, Claude, Groq, Ollama) with streaming and retries

## Tech stack
Electron · React · TypeScript

## Engineering
ADR-driven development with 715 unit test suites and 9 end-to-end test suites.
